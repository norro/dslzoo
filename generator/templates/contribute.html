Contribute

We are constantly updating and extending the Robotics DSL Zoo and are waiting for your input!

All sources of this Robotics DSL Zoo are hosted in GitHub in corlab/dslzoo. Feel free to fork the repository and make additions to the source files. Check the GitHub help on pull requests on how to request your changes to be added to the zoo.

  1. Go on GitHub and fork the corlab/dslzoo repository.
  2. Add a new entry to dslzoo.bib of your fork. The format is: 
    @inproceedings{surnameyearfirstword,
  annote = {Your two to three sentence summary of the core contribution},
  author = {John Doe and Other Authors},
  booktitle = {International Conference on DSL Stuff},
  doi = {12.3456/DOI.1234.1234567},
  isbn = {978-1-2345-5678-9},
  keywords = {dsl-zoo, ...},
  month = jan,
  pages = {12--34},
  publisher = {IEEE},
  title = {Publication Title},
  url = {http://publication.link},
  year = {2020},
  zoo-subdomains = {{ '{' }}{{ kinds['subdomain'].terms|map(attribute='name')|join(', ') }}{{ '}' }},
  zoo-ap-subdomains = {{ '{' }}{{ kinds['discipline'].terms|map(attribute='name')|join(', ') }}{{ '}' }},
  zoo-phases = {{ '{' }}{{ kinds['phase'].terms|map(attribute='name')|join(', ') }}{{ '}' }},
  zoo-tool = {DSL Tool / Workbench (e.g. 'EMF xtext')},
  zoo-website = {http://dsl.homepage.link},
  zoo-download = {http://dsl.download.link},
}

    The values of the three zoo- classification fields are lists; use the terms as spelled here, others get no page. There are a lot of free BibTeX tools out there to support you with this format, some of them might hide the zoo-specific custom fields though.

  3. After you added a publication, place a pull request (preferably one for each publication) to corlab/dslzoo.
